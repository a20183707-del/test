# BSG — Extractor de datos desde documentos

Aplicación local para Windows con archivos o texto libre, campos definidos manualmente, Gemini con salida estructurada nativa, validación por código y un revisor independiente.

Ejecuta **`iniciar.bat`** desde esta carpeta. Consulta [instalación y uso](extractor-documental/README.md), [arquitectura](extractor-documental/ARCHITECTURE.md) y [checklist estricto del profesor](extractor-documental/docs/CHECKLIST_PROFESOR.md).

El código no contiene credenciales ni documentos privados. Las pruebas locales y las ejecuciones reales del proveedor se documentan por separado en [verificación](extractor-documental/docs/VERIFICATION.md). El lote real de cinco contratos sintéticos produjo un exitoso, tres parciales y un fallido, con revisión independiente y supervisión por 20% de éxito. El checklist conserva los pendientes de la entrega sin inventar cumplimiento.
